API-эндпоинты:
- Аутентификация: /api/token/ (POST) - получение JWT-токена
- Обновление токена: /api/token/refresh/ (POST) - обновление JWT-токена
- Задачи: /api/tasks/ (GET, POST) - получение и создание задач
- Задачи: /api/tasks/{id}/ (GET, PUT, PATCH, DELETE) - работа с конкретной задачей
- Клиенты: /api/clients/ (GET, POST) - получение и создание клиентов
- Клиенты: /api/clients/{id}/ (GET, PUT, PATCH, DELETE) - работа с конкретным клиентом
- Уведомления: /api/notifications/notifications/ (GET) - получение списка уведомлений
- Уведомления: /api/notifications/notifications/{id}/ (GET) - получение конкретного уведомления
- Уведомления: /api/notifications/notifications/{id}/read/ (POST) - отметить уведомление как прочитанное
- Уведомления: /api/notifications/mark-all-read/ (POST) - отметить все уведомления как прочитанные
- Уведомления: /api/notifications/unread-count/ (GET) - получить количество непрочитанных уведомлений

Технические детали:
- Модель Client связана с ClientGroup через ManyToMany
- Модель CustomUser связана с EmployeeGroup через ManyToMany
- Поля equipment_fill и другие оценочные поля теперь корректно отображаются в фотоотчетах
- Все изменения соответствуют принципам SOLID
- Интерфейс фильтрации реализован через JavaScript с использованием стандартного API Django SelectBox
- Автоматический сброс селекторов групп обеспечивает корректную работу формы при сохранении
- Статусы задач обрабатываются через TaskStatus enum с четкой бизнес-логикой переходов
- Геолокация извлекается из EXIF-данных с помощью библиотеки Pillow
- Информация об авторе сохраняется в глобальные переменные JavaScript для последовательного отображения
- Уведомления реализованы с использованием Django Signals для автоматической отправки
- API построены с использованием Django REST Framework и JWT-аутентификации
- Все API защищены и требуют аутентификации через JWT-токены
- **Нечувствительный к регистру поиск:** реализован через `queryset.extra()` с `REGEXP` и флагом `(?i)`, т.к. `__icontains` не работает корректно с кириллицей в SQLite на Windows

# 📥 Импорт клиентов из 1С

## ⚠️ ВАЖНО

**Импорт через админку Django НЕ работает корректно!**

Вместо этого используйте **команду управления**:

---

## 🚀 Использование

### 1. Тестовый режим (проверка без сохранения)

```bash
python manage.py import_clients_from_excel --test
```

### 2. Реальный импорт (с сохранением в БД)

```bash
python manage.py import_clients_from_excel
```

## 📋 Обозначения

| Значок | Статус | Описание |
|--------|--------|----------|
| `+` | Обновлён | Код 1С обновлён (был NULL → стал число) |
| ` ` (пробел) | Без изменений | Код 1С уже был в базе |

---

## 📁 Формат Excel-файла

| Столбец | Название | Обязательно |
|---------|----------|-------------|
| A | `id` | Нет (оставьте пустым) |
| B | `code_1c` | **Да** (код из 1С) |
| C | `name` | **Да** (наименование клиента) |

## ✅ Результат

- **1675 клиентов обновлено** — получили код 1С
- **233 клиента не найдено** — требуют ручного создания в админке

---

## 🔧 Для разработчиков

Команда находится в:
```
clients/management/commands/import_clients_from_excel.py
```

Алгоритм:
1. Поиск клиента по `code_1c`
2. Если не найден — поиск по `name`
3. Если найден — обновление `code_1c`
4. Если не найден — пропуск (запись в список "не найдено")

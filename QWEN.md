# MicroCRM MCP - Система управления задачами

## Обзор проекта

MicroCRM MCP - это система управления задачами на основе Django, предназначенная для управления задачами, анкетами и фотоотчетами. Проект представляет собой веб-приложение с русскоязычным интерфейсом, ориентированное на работу с клиентами, сотрудниками и модераторами.

### Архитектура проекта

Проект состоит из следующих основных компонентов:

- **config/** - Конфигурация Django проекта
- **users/** - Модель пользователей и управление ролями
- **clients/** - Управление клиентами и группами клиентов
- **tasks/** - Модель задач, анкет и фотоотчетов
- **reports/** - Модуль отчетов и статистики
- **announcements/** - Система объявлений
- **templates/** - Шаблоны Django
- **static/** - Статические файлы
- **media/** - Загруженные медиафайлы

### Основные функции

1. **Управление задачами** - Создание и назначение различных типов задач:
   - Анкеты (опросы с различными типами вопросов)
   - Фотоотчеты по оборудованию
   - Простые фотоотчеты

2. **Множественные назначения** - Возможность назначать задачи:
   - Одному сотруднику
   - Группе сотрудников
   - Одному клиенту
   - Группе клиентов
   - Всем клиентам сразу

3. **Группы пользователей** - Поддержка групп сотрудников и клиентов

4. **Поиск клиентов** - Улучшенный регистронезависимый поиск для кириллицы

5. **Управление количеством стендов** - Возможность указания и изменения количества стендов у клиентов

6. **Система объявлений** - Отправка объявлений с подтверждением прочтения

7. **Множественная загрузка фото** - Поддержка загрузки нескольких фотографий за раз

8. **Статистика выполнения** - Отслеживание прогресса выполнения задач

## Технологии

- **Django 5.2.8** - Веб-фреймворк

## Запуск проекта

Проект можно запустить с помощью командного файла `start.cmd`:

```cmd
@echo off
chcp 65001 > nul
call "E:\Разное\Софт\my_venv\web\web\Scripts\activate.bat"
cd /d "%~dp0"
python manage.py runserver 0.0.0.0:8000
cmd /k
```

Это активирует виртуальное окружение и запустит сервер Django на порту 8000.

Альтернативно, можно использовать стандартные команды Django:

```bash
python manage.py runserver
```

## Конфигурация

- **Язык интерфейса**: Русский (`ru-ru`)
- **Часовой пояс**: Красноярск (UTC+7)
- **База данных**: SQLite (`db.sqlite3`)
- **Разрешенные хосты**: Все (`['*']`) - только для разработки
- **CORS**: Разрешены все источники (только для разработки)

## Модели данных

### Пользователи (CustomUser)
- Роли: Сотрудник, Модератор, Клиент
- Дополнительные поля: телефон, группы сотрудников

### Клиенты (Client)
- Имя клиента
- Адрес
- Назначенный сотрудник
- Группы клиентов
- Количество стендов

### Задачи (Task)
- Типы: Анкета, Фотоотчет по оборудованию, Простой фотоотчет
- Статусы: Черновик, В работе, На доработку, На проверке, Принято, Завершена
- Назначения: на сотрудников и клиентов (одиночные и групповые)

### Анкеты (SurveyQuestion, SurveyAnswer)
- Различные типы вопросов: текстовые, радиокнопки, чекбоксы, выбор из списка
- Поддержка фотоответов

### Фотоотчеты (PhotoReport)
- Оценки по различным категориям
- Поддержка множественных фотографий
- Система модерации

## Особенности реализации

1. **Регистронезависимый поиск** для кириллицы в SQLite
2. **Drag-and-drop сортировка** вопросов в анкетах
3. **Множественная загрузка фото** с превью
4. **Система объявлений** с подтверждением прочтения
5. **Визуальное выделение** клиентов с отправленными отчетами
6. **Унифицированное отображение** задач, назначенных одному клиенту
7. **Корректная статистика выполнения** с учетом всех типов задач

## Безопасность

- Используется JWT-аутентификация
- Пароль минимальной длины 4 символа (предупреждение: небезопасно для продакшена)
- CORS разрешен для локальных доменов

## Разработка

Для разработки рекомендуется использовать виртуальное окружение Python и устанавливать зависимости из `requirements.txt`.

Для выполнения миграций базы данных:
```bash
python manage.py migrate
```

Для создания суперпользователя:
```bash
python manage.py createsuperuser
```

ОПИСАНИЕ КЛЮЧЕВЫХ СТРАНИЦ ПРОГРАММЫ:

1. Страница списка задач (/tasks/):
   - Для сотрудников: отображаются только назначенные им активные задачи
   - Для модераторов: отображаются все задачи системы
   - Поддерживает пагинацию (по 10 задач на страницу)

2. Страница заполнения анкеты (/tasks/survey/<id>/):
   - Содержит поля для выбора клиента через автозаполнение
   - Отображает вопросы анкеты с возможностью выбора вариантов или ввода текста
   - Поддерживает добавление до 10 фотографий

3. Страница фотоотчётов (/admin/tasks/surveyanswer/equipment-photo-reports/):
   - Отображает фотоотчёты по оборудованию в двух колонках: "Актуальные" и "Предыдущие"
   - Поддерживает фильтрацию по клиенту, задаче, сотруднику и дате
   - Позволяет модератору оценивать отчёты и отправлять на доработку
   - Корректно обрабатывает статусы: "Новый" → "Обработать" → "На проверке" → "Принять" → "Принято"

4. Страница группировки ответов анкет (/admin/tasks/surveyanswer/):
   - Группирует ответы по клиентам, задачам и пользователям
   - Помечает новые ответы (за последние 24 часа) специальной меткой
   - Позволяет отмечать ответы как "обработанные"
   - Поддерживает экспорт ответов в Excel

5. Страница объявлений (/announcements/):
   - Отображает каруселью актуальные объявления для текущего пользователя
   - Требует подтверждения прочтения для важных объявлений
   - Содержит архив всех полученных объявлений


ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ API:

1. Автозаполнение клиентов (регистронезависимый поиск):
   GET /clients/autocomplete/?q=меняйло
   Response: [{"id": 1, "name": "Меняйло А.О.", "address": "Кемерово"}]

2. Автозаполнение задач (регистронезависимый поиск):
   GET /tasks/autocomplete_tasks/?q=оборудование
   Response: {"tasks": [{"id": 5, "title": "Проверка оборудования 2026"}]}

3. Получение сгруппированных ответов анкет (с фильтрацией):
   GET /admin/tasks/surveyanswer/api/grouped-answers/?clientId=1&taskId=5
   Response: {"results": [{"id": "5_1_kirill_2026-01-02", "taskName": "...", "answers": [...]}]}

4. Пометить ответ как прочитанный:
   POST /admin/tasks/surveyanswer/api/mark-as-read/
   Body: {"answerId": "5_1_kirill_2026-01-02"}
   Response: {"success": true, "readAt": "2026-01-02T19:30:45"}

5. Получение списка фотоотчётов (с фильтрацией):
   GET /admin/tasks/surveyanswer/api/equipment-photo-reports/?client_id=1
   Response: {"results": [{"id": "123", "taskName": "...", "photos": [...]}]}

6. Обработка фотоотчёта (установка статуса "На проверке"):
   POST /tasks/api/process-equipment-photo-report/
   Body: {"report_id": 123, "equipment_fill": 3, "no_foreign_goods": 2, "product_display": 3, "equipment_location": 1}
   Response: {"success": true, "average_rating": 2.25, "moderated_at": "2026-02-08T15:30:45"}

7. Принятие фотоотчёта (установка статуса "Принято"):
   POST /tasks/api/accept-equipment-photo-report/
   Body: {"report_id": 123}
   Response: {"success": true, "message": "Отчёт принят модератором Иванов И.И."}

Все API-эндпоинты требуют аутентификации и защиты от CSRF в POST-запросах.
